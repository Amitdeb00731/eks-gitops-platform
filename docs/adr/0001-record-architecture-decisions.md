# 0001: Record architecture decisions

**Status:** accepted.

## Context

The platform makes several choices that a reviewer will reasonably question:
which tools, which environments, how much to run live. Those choices are easier
to trust when the reasoning is written down beside the code.

## Decision

Record each significant decision as a short, numbered architecture decision
record in `docs/adr/`, using the context, decision and consequences structure.

## Consequences

A reader can follow the reasoning without asking. Decisions can be revisited by
superseding a record rather than quietly changing direction.
