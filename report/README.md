# report

The written deliverables that sit above the code (Phase 9).

- The operations runbook: how the platform is deployed, observed, and recovered,
  written for an engineer who did not build it.
- The controls mapping: each control the platform implements, traced to NIST
  SSDF, SOX ITGC, and the UK PRA and FCA operational-resilience expectations.
- The business report: what the platform protects and what it costs, written
  for a reader who does not read Terraform.

These documents translate the build into the language a reviewer, an auditor,
and a hiring panel each read in. The code proves the platform runs; the reports
explain why it is trustworthy.
